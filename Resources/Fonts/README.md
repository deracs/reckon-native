# Newsreader

The desktop wordmark uses the unmodified Newsreader variable font at weight 600 (SemiBold) and optical size 26. Interface text retains the macOS system font.

Source: [Google Fonts, Newsreader](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/newsreader), pinned at commit `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`.

`Newsreader.ttf` is upstream's `Newsreader[opsz,wght].ttf`. Its SIL Open Font License is included in `Newsreader-OFL.txt` and ships with the app. The font is registered for Reckon's process only; it is not installed on the Mac and makes no network requests.
