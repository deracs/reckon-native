# Desktop design reference

The [light-blue concept](desktop-light-blue-concept.png) is an AI-generated design reference produced with the built-in imagegen tool. It is not an app screenshot. Figures and labels in the concept are illustrative.

The approved brief combines Linear-like compact navigation and typography with Copilot-like financial presentation. Keep light mode, a warm white canvas, a pale sidebar, soft blue selections, quiet separators, a large liquid balance, an integrated green forecast, a compact cashflow and upcoming-events rail, and recent activity below. Retain native Mac window controls. Avoid purple accents.

The implementation reuses Reckon's existing accounts, currencies, forecast calculations, and session. It adds a full desktop window alongside the menu-bar dropdown. The app's actual fictional-data screenshots are in [the README](../../README.md#desktop-preview).
