# Backend performance — 21 October 2026

The bundled backend ran on Apple M3 Pro (arm64) with Node v24.21.0 and Effect 4.0.5.
Each scenario used 20 fresh backend processes. The fixture contained three accounts and 3,000 posted transactions across six months. Each source page contained at most 500 transactions.

| Measurement | Local fixture median | Local fixture p95 | 50 ms per source response median | 50 ms per source response p95 |
| --- | ---: | ---: | ---: | ---: |
| Backend startup | 77.4 ms | 133.0 ms | 85.5 ms | 93.0 ms |
| First dashboard | 84.8 ms | 113.1 ms | 291.8 ms | 304.8 ms |
| Fresh dashboard reload | 34.3 ms | 42.6 ms | 194.9 ms | 205.2 ms |
| Backend RSS at readiness | 76.7 MiB | 76.9 MiB | 76.7 MiB | 76.8 MiB |
| Backend RSS after first dashboard | 134.6 MiB | 136.0 MiB | 132.6 MiB | 133.9 MiB |
| Backend RSS after fresh reload | 144.9 MiB | 145.9 MiB | 142.9 MiB | 143.6 MiB |

The median is the mean of the two central observations. The p95 value uses the nearest-rank method.

Startup measures process creation through the ready handshake. The backend makes no source request before readiness. The harness does not flush OS caches.

Dashboard time covers eight concurrent authenticated HTTP requests through JSON decode in the Node harness. Each load uses a fresh snapshot UUID. The first dashboard made ten upstream requests: one account page, six posted-history pages, and three pending-history pages. Each fresh reload made nine upstream requests because the account list remained cached. Each history page ran once per reload.

The RSS samples cover only the backend process. They include shared resident pages. They do not measure peak memory, retained JavaScript heap, or the full Swift app footprint. The harness samples RSS outside the timed intervals.

These results exclude Swift JSON decode, SwiftUI rendering, Keychain access, and live Akahu latency. The 50 ms scenario applies a controlled delay to each local source response. It does not predict live bank performance. This report establishes the current baseline. It contains no before-and-after comparison.

## Reproduce

Build the app first. Run this command from the repository root:

```sh
node scripts/measure-backend.mjs --runs 20 --output .build/backend-performance.json
```

The command starts only local fixture servers and child backends. It uses synthetic credentials and transactions. It does not read saved tokens or bank data.

[Raw samples and environment](backend-2026-10-21.json) include the exact bundle SHA-256 and size (976,448 bytes).
